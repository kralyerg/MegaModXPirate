# MegaModXPirate

A parody "translation" for [MegaMod X](https://worldofbanished.com/megamod/), a large content mod for the city-builder game [Banished](https://www.shiningrocksoftware.com/). Rather than a real language, this rewrites every menu, tooltip, and building label into pirate dialect ("ye", "arrr", and all). It's a standalone, StringTable-only mod — it overrides UI text only, doesn't touch textures, models, or gameplay, and doesn't require recompiling MegaMod itself.

Load this mod **above MegaMod X** in your mod list. It will show up red in the mod list — that's expected, since it deliberately overrides the same files MegaMod X provides.

Download the compiled mod and see the real language translations too at the [Translations page](https://worldofbanished.com/megamod/translations.html).

## This is a joke, not a real localization

There's no "correctness" to check against — no native speaker review needed here, just whether a line is funny/fitting or not. If you think a line could be punchier, more in-character, or is just plain unfunny, feel free to suggest a better version. See [CONTRIBUTING.md](CONTRIBUTING.md) for how, including the tone/style guide this translation tries to follow.
