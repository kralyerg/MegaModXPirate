# MegaModXPirate

Ahoy! A parody "translation" fer [MegaMod X](https://worldofbanished.com/megamod/), a mighty content mod fer the city-builder game [Banished](https://www.shiningrocksoftware.com/). Rather than a real tongue, this here mod rewrites every menu, tooltip, an' buildin' label into pirate speak ("ye", "arrr", an' all). She be a standalone, StringTable-only mod — overrides UI text only, don't touch textures, models, or gameplay, an' ye needn't recompile MegaMod herself.

Load this mod **above MegaMod X** in yer mod list. She'll show up red in the list — that be expected, since she deliberately overrides the same files MegaMod X provides.

Fetch the compiled mod an' see the real language translations too at the [Translations page](https://worldofbanished.com/megamod/translations.html).

## This be a jest, not a real localization

There be no "correctness" to check against — no native speaker review needed here, just whether a line be funny or fittin' or not. If ye reckon a line could be punchier, more in-character, or just plain unfunny, feel free to suggest a better version. See [CONTRIBUTING.md](CONTRIBUTING.md) fer how, includin' the tone/style guide this translation tries to follow.
